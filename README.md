# honey

> **BIRTHDAY.EXE** — An Unhinged, Scroll-Driven 3D Birthday Experience for Aki 🎂

## Features
- **Scroll-Driven Character Journey**: Persistent full-body photograph of Aki with smooth, cinematic GSAP ScrollTrigger camera choreography zooming through his headwrap, serene face, torso, knees, and barefoot finale.
- **Dynamic Birthday Newspaper**: Real-time date calculator displaying today's date, calculating birthday milestones dynamically ("today is my birthday", "yesterday was my birthday", etc.).
- **Interactive Birthday Card**: Paper envelope with wax seal, authentic heartfelt note, and Polaroid photo frame.
- **3D Mini-Game — "PROTECT HIS LAST BRAIN CELL"**: Low-poly Three.js arcade survival game where players use a shield to defend Aki's lone brain cell from incoming alarms, exams, crates, and responsibilities while collecting golden samosas.
- **Paper-Cut Aesthetic**: Playful typography, collage clippings, Emil Kowalski fluid micro-interactions, Better-UI press physics, and sound effects synthesized with Web Audio API.
- **Authentic Social Touch**: Footer badge linking directly to Aki's handle: `📸 @aki.medicos`.

## Tech Stack
- **Framework**: [Astro](https://astro.build/)
- **Animation**: GSAP + ScrollTrigger
- **3D Scene & Game**: Three.js
- **Styling**: Vanilla CSS with modern tokens, responsive grids, and paper-cut design system
- **Audio**: Web Audio API procedural sound synthesizer (zero external audio asset dependencies)
- **Effects**: canvas-confetti

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
